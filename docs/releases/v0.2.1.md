## Firmware

- Firmware updates from the app work. Until now an update stopped right
  after it started with "The device stopped acknowledging": the device never
  noticed that the phone had received its first reply, so it held back every
  reply after it.
- A device with firmware 0.1.0 or 0.2.0 has that fault itself, so it can't
  take this update over Bluetooth. Install 0.2.1 on it once over USB (see
  "Install a release over USB" in the firmware README). From then on,
  updates from the app work.
